# 风格分布系统

版本 **1.2.0**。可直接部署到 GitHub Pages 的静态网站，无需后端、API Key、安装依赖或构建。

## 上传与发布

1. 解压交付的 ZIP。将解压后的**文件与目录放在仓库根目录**，确认根目录能看到 `index.html`，不要只上传 ZIP。
2. 推荐用 GitHub Desktop 将这个目录作为仓库发布到 GitHub；图片文件较多，网页上传需分批。
3. 在 GitHub 仓库进入 **Settings → Pages**，Source 选 **Deploy from a branch**，分支选 `main`，目录选 **/ (root)**，保存。
4. 等待 Pages 部署成功，打开该页面提供的网址，通常是 `https://你的用户名.github.io/仓库名/`。

本项目使用相对路径，支持 GitHub Pages 仓库子路径。`art-analysis.html` 保留为旧入口并跳转到 `index.html`。

## 本地查看与检查

直接双击 `index.html` 即可浏览。也可在本目录运行 `python -m http.server 8000` 后访问 `http://localhost:8000`。

安装 Node.js 20 或更高版本后运行 `npm test`，无需 `npm install`。测试检查站内资源、数据数量、交互逻辑与标注布局；采用 DOM 行为模型，并非真实浏览器测试。发布前请在浏览器查看显隐、悬停、全屏与配图。

## 已有内容

- 原100款全品类游戏案例、休闲榜101款（原美国 iPhone 免费休闲榜100款 + 补充MONOPOLY GO!）、40个风格方向。
- X轴固定为形体写实度（卡通→写实），Y轴可切换表现风格化、造型复杂度或世界年代；Y轴后的“指标详情”解释各项口径。另有10款起、上限随集合数量增长的滑杆、搜索、分类、缩放和全屏。
- 游戏名字显隐、独立编号、悬停简介、详情配图，以及 SVG / JSON 导出。
- 原角色图鉴、复杂度、年代、形体表现等历史分析页面及其下载文件。

全品类游戏是案例集，**不是 App Store 全品类排名**。休闲榜为 **MSY Games 2026-11-05 快照**，不是实时榜。休闲榜尚无年代和复杂度评分，相关坐标轴禁用。评分为人工比较；未知年代保留空值。

## 文件结构与编辑位置

| 文件 | 用途 |
| --- | --- |
| `index.html` | 当前网站入口、页面结构与说明 |
| `assets/css/art-explorer.css` | 页面样式 |
| `assets/js/art-explorer-ui.js` | 按钮、筛选、滑杆、详情与悬停交互 |
| `assets/js/art-explorer-core.js` | 坐标、名称及编号布局、SVG 绘制 |
| `assets/js/data.js` | 主站唯一数据源，包含原分析评分、简介、来源与图片路径 |
| `assets/images/` | 412张本地参考图（休闲312张 + 原案例100张） |
| `character-styles.html` 等页面 | 保留的历史分析快照 |
| `tests/` | 无依赖验证脚本 |
| `CHANGELOG.md` | 版本改动记录 |
| `AGENTS.md` | 后续迭代与增量交付约定 |
| `tools/package-release.py` | 全量包／差异包打包工具 |
| `release-manifest.json` | 已交付版本的路径与 SHA-256，用于比对下次变更 |

页面、脚本、样式和图片已分离，改动样式或交互不必重新上传全部图片。`data.js` 使用 `window.DATA` 赋值，避免本地文件模式下的 JSON 请求限制。无需重新生成 HTML。

历史页面是保留的快照；根目录 `*-matrix-data.json` 也是历史数据，不驱动主站。修改主站数据时编辑 `assets/js/data.js`；只有需要同步历史页面时才额外修改它们。

## 后续如何迭代

默认只修改本地网站并说明改动；仅在用户主动索要时生成更新包。届时交付**新增／修改文件**、`UPDATE.md`、删除路径和新版本清单，按仓库实际文件核对，避免跳过中间版本造成缺失。将包内文件按原路径合并覆盖仓库，无需重复上传未改动图片。

开始下一次迭代时请提供仓库地址或当前版本号；如果你自行修改了文件，请一并说明，以免覆盖。当前交付基线为 `v1.2.0`，`release-manifest.json` 是精确文件指纹；打包前也需核对仓库实际文件。

维护者在改动完成并更新 `package.json` 版本和 `CHANGELOG.md` 后，可运行：

```sh
python tools/package-release.py --version 1.2.1 --baseline release-manifest.json
```

更新包写入 `releases/`；打包工具会先读取旧清单再写入新清单。下一轮以本轮的新清单为基线。不要在改动完成前覆盖旧清单。首次全量打包用 `--full`。

## 图片与资料

主站两组201款游戏的412张参考图均随包提供，可离线浏览。原100款中失效或不适合作为取色依据的图片已补充同一游戏的有效来源，详情注明替换依据；宝可梦为3幅215px官方插画拼图。历史快照仍引用外站图片。

名字和独立编号底板采用当前参考图的代表色，保留HEX、裁切范围、图源和SHA-256；文字自动采用黑/白色，201款最低对比度不低于4.5:1。配色是对这组画面的归纳，不是游戏全场景唯一主色或品牌标准色。可打开 `palette-reference.html` 逐项对照。

新增休闲样本使用唯一key、`entryType: supplement`、`originalRank: null` 和“补”编号，不冒充原快照排名；补充项列前，原#001–#100顺序保持。每项应补齐本地参考图、来源与labelPalette，再运行检查。栏目简称“休闲榜”，数量单独显示。

游戏名称、截图及设定图属于其原权利人；保留来源不代表获得图片的再授权。本包没有为这些第三方素材声明开源许可。

隐藏名称时编号显示纯数字，原案例和原休闲榜去掉前缀及前导零；补充项用独立的 plotNumber（MONOPOLY GO! 为101）。数字字号9px，底板收紧，仍由引线连接真实点位。

## v1.1 界面与操作

- 主站采用浅色研究工作台，统一文字层级、控件、标签、详情与移动端布局；历史图鉴与原始分析页继续作为快照保留。
- 三组集合分别命名为全品类案例、休闲榜、风格方向，数量单独显示；休闲榜仍是快照与补充项。
- 快捷视角显示当前选中状态。未评估的组合禁用，不会自动切到其他集合；切换可用视角保留搜索和分类。
- 搜索仍在滑杆限定范围中进行。筛选条可一键清除；无结果时可保持关键词、扩大到全部样本搜索。
- 样本详情先展示视觉参考，再展示评分、设计特征和可展开的依据；全屏提供“样本详情”入口。
- 仅数字模式仍采用9px编号，悬停或选择标注时强调坐标引线。

本次通过资源检查、93组图表布局检查、交互模型及配色核验；另核对主站HTML结构、CSS语法与导出图表。浏览器工具限制本地file页面访问，未做真实浏览器布局与交互验证。

样本清单的编号下方显示该游戏的参考色色块，与图表标签使用同一份配色数据；悬停色块可查看HEX值。风格方向未设置游戏参考色时不显示色块。
